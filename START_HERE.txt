TYPEKEEPER: ENCHANTED LIBRARY — 3.1.0

Extract this archive before playing.

Simplest: open PLAY.html in a desktop browser.
Recommended for stable saves: run START_MAC.command, START_WINDOWS.bat,
or bash START_LINUX.sh. These use an existing Python 3 or Node.js.
The full game is also prebuilt in dist/.

UPGRADING: keep v3.0 and export its save before deleting anything.
Stop its local server first (Control+C), then run this version at the same
address, port and browser profile. Original save keys are never overwritten.
Music, artwork and layout have not been redesigned.

3.1 focuses on fair pacing, spell combinations, word/readability fairness,
chapter retries, consistent continuation, score categories and failure recovery.
New-rule scores and old-rule scores are deliberately separated.

README.md — setup, commands, upgrade behavior
PLAY.html — embedded complete game
src/ — complete editable source
public/assets/ + asset-source/ — unchanged runtime art/music and masters
docs/RELEASE_NOTES.md — what changed and why
docs/QA_REPORT.md — measured checks and explicit testing limitations

This is the browser game and full source, not a Steam-installed desktop binary.
