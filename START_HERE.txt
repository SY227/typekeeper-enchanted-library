TYPEKEEPER: ENCHANTED LIBRARY — 3.2

PLAY: Open PLAY.html, or run START_MAC.command / START_WINDOWS.bat.
The launchers need existing Python 3 or Node. PLAY.html does not.

UPDATE AN EXISTING REPO:
Run UPDATE_EXISTING_MAC.command from the extracted v3.2 folder.
By default it updates ~/Downloads/Typekeeper_Enchanted_Library_v3_1
AFTER a backup. .git, .vercel, .env files and existing vercel.json are retained.
This does not push or deploy. README.md has the subsequent Git commands.

KEEP YOUR PROGRESS:
Export a save from Records before changing versions/domains.
Old settings, unlocks and valid bookmarks migrate at the same browser origin.
Scores under earlier rules remain Legacy. Start a fresh run for current records.
Returning users keep their existing mute/music preferences.

CONTROLS:
Type a word + Enter. 1 Fire, 2 Ice, 3 Slow, 4 Wind. Escape pauses.
The new pressure score and typing shimmer can be toggled in Settings.

This is a complete browser release candidate, not a native Steam executable.
See docs/QA_REPORT.md for the executed tests and remaining human/device gates.
