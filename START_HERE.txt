TYPEKEEPER: ENCHANTED LIBRARY — v3.6.3
OPEN ATRIUM

Extract this entire folder first.
Open PLAY.html to play the self-contained offline game.
Mac local-server option: bash START_MAC.command
Windows local-server option: START_WINDOWS.bat
The launcher/browser title should show v3.6.3.

The green ruled screen is removed. Words now occupy the original library space,
with softly graded depth and lantern light rather than a replacement UI panel.
Gameplay, UI positions, audio and saved-progress rules remain unchanged.

Continue, Start from Chapter 1, and unlocked Chapters are retained.
Restarting your journey does NOT erase your chapter unlocks, stars or best scores.

Before switching a file location, browser, website address or port:
Records -> Export save. At the new location use Records -> Import save.
Stop the old local server with Control+C before starting the new server.
