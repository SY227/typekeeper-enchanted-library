TYPEKEEPER: ENCHANTED LIBRARY — 3.2.1

PLAY: Open PLAY.html, or use START_MAC.command / START_WINDOWS.bat.
The local-server launchers require Python 3.9+ or Node 20+. PLAY.html does not.

THIS UPDATE: A gentler opening and scarcer spells. Campaign starts empty; the
sixth card offers one earned ICE book. Capacity is two per spell. Other art,
music, effects, controls, scoring and the 48-chapter structure are retained.

UPDATE EXISTING PROJECT:
Run UPDATE_EXISTING_MAC.command. The default target is
~/Downloads/Typekeeper_Enchanted_Library_v3_1, even if it already contains v3.2.
The helper makes a backup and preserves .git, .vercel, .env and vercel.json.
It performs no remote push or deployment. README.md contains subsequent commands.

SAVES:
Export before updating. Preferences, stars, unlocks and valid bookmarks migrate
at the same browser/domain. Old saved bytes remain untouched. Old totals stay
in Legacy. Carried inventory above two per type is capped at two in this version.
Start a new campaign to experience the new opening and earn current records.

CONTROLS:
Type + Enter. 1 Fire, 2 Ice, 3 Slow, 4 Wind. Escape pauses.
Practice/Endless keep their separately scored starter kits.

See docs/QA_REPORT.md for executed tests and honest validation limits.
