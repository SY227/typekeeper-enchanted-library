# v3.4.0 presentation specification

See CHAPTER_ART_SPEC.md for all 48 title-specific room treatments. All main playfield,
HUD, typewriter, spell book and input positions remain the accepted v3.3.6 layout.

FIRE uses a 0.65-second original rising flame/char cue. ICE follows the existing
six-second freeze and a 0.7-second decorative thaw. Their composition is below live
word text. ICE textures leave the lettering area clear. Existing effects and
readiness captions respect motion/contrast settings and maintain keyboard selection.

The approved imperial scroll layout and one-word/one-baseline invariant are retained.
The QA report distinguishes cache, native-raster, UI-journey, model-boundary and
full-flow checks. Nothing here is a promise of matching unseen video frames.
