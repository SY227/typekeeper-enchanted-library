# Asset and source provenance

The user-supplied `Typing_Maniac_Storykeeper_v2_Full_App(1).zip` is the source baseline. Its library illustration, isolated red-haired character, registered expression variants, paper material, original spell vectors and game source are retained and polished. The imagery is not downloaded or extracted from the historical game's installation. No claim is made that these are original publisher assets or pixel-identical recreations.

The supplied v2 expressions are deterministic local deformations/paintovers of its registered typist master. Their source recipe and alignment data remain included. The current release does not claim that a new 3D character was rendered in Blender or Unreal.

New music **Lanterns & Letters** is an original authored arrangement rendered with the included deterministic synthesis code. No third-party sampled recordings, SoundFonts, or purchased tracks are used. See MUSIC_PRODUCTION.md for the distinction between the actual custom sound, editable MIDI, and lossless masters.

The Typekeeper title, browser metadata and typewriter text are live typography using available system serif/sans-serif fallbacks. The quill favicon is an editable SVG master. No font binaries are distributed. Platform font rendering can differ and must be checked on intended browsers.

All game state is live code. Screenshots under `docs/screenshots/` come from the running embedded application with labeled controlled states, not generated mockups. The board contains local user records only; no invented worldwide competitors are presented.

`public/assets/manifest.json`, `dist/build-manifest.json`, and root `SHA256SUMS.txt` document delivered bytes. These are integrity records, not a trademark clearance, publisher affiliation claim or legal approval of a commercial launch.
