# Release boundaries

This is the complete Typekeeper 3.0 production build plus source, not a certification that every public-launch gate has been passed.

The original longer video's frames/audio remain unavailable. Graphics, progression and music are an independently produced adaptation; numerical/video parity is not asserted. Shared Facebook/global leaderboards are not implemented: the interface explicitly labels local records.

Automated browser interaction and audio checks ran in Chromium 144 on Linux using the exported PLAY.html loaded in memory. Normal localhost/file URL navigation is blocked by the managed browser, so HTTP bytes/MIME and browser execution are reported as separate checks. Real Safari, Firefox, Edge, macOS/Windows launcher integration, physical-device audio, and live hosting are not certified here.

Desktop physical-keyboard play is the primary target. Proportional small-screen scaling is not a claim of good phone virtual-keyboard ergonomics or complete screen-reader gameplay support. Focus trapping, labels, contrast, reduced motion and visible spell states improve accessibility without claiming an audit certification.

The 36 synthetic difficulty runs use perfect-spelling deterministic agents. They validate model behavior, not a human fun/difficulty assessment. Human first-time-player, experienced-player, late-game and music-loop listening sessions remain valuable release gates.

The title and delivered assets have not undergone commercial identity/legal clearance. No original-publisher affiliation is claimed. Source/music masters are supplied for further review and production work. The optional Unreal/Blender artwork tools were not executed; they are not a native game project.
