# Typekeeper — style and interaction guide

Retain the v1 warm illustrated library: deep teal shelves, timber framing, cream paper, gold/brass instrumentation, red-haired typist, and visible books. The 1200×900 logical composition scales proportionally; desktop keyboard play is primary. Do not turn the score HUD into a generic dashboard or replace functional controls with a flattened screenshot.

Spell identity remains redundant: FIRE = orange + flame + key 1; ICE = cyan + snowflake + key 2; SLOW = warm gold + hourglass + key 3; WIND = lilac + gust + key 4. Each also has a plain-language name, stock count/pips, and readiness label. READY glow has a slow 1.8-second cycle. The acquisition accent is temporary. Timer seconds and ACTIVE labels remain readable while a power is running.

Character reactions come from registered variants, not color tint alone. Preserve the pivot and proportional head/body placement in `asset-source/expressions/rig.json`. Calm/focused are restrained; worry changes brow/mouth; alarm and critical show more obvious distress and localized sweat. Relief/celebration should not keep playing into another run. Reduced motion removes glow/decorative motion but never removes the informational facial change.

Atlas and results screens use parchment, pressed green/gold buttons, serif titles, fine rules, wing seals, and earned mastery stars. Locked stages are visibly disabled. A result screen names the next stage or explicitly ends the 48-stage campaign. No score table is populated with fictional players.

Live word text uses local serif fallbacks, not bundled font files. Card width is determined using conservative glyph advances rather than character count alone, protecting wide words such as CLOCKWORK. Text remains separate from image masters. Review live wide/power cards and high-pressure states at the target display size; concept art is not a substitute for this check.

This is the implemented visual direction. It is not a claim that the source video used these exact dimensions, fonts, colors, or motion timings.


## V3 editorial standard

No website masthead or footer around the game, no edition line, no account/privacy marketing labels in the playfield. One title lockup and subtitle. Use live brass/cream type, quill identity, green primary controls and warm keyboard-focus outlines. Do not erase useful focus/readiness feedback to achieve a cleaner screenshot.

Keep default HUD to score, chapter progress, streak, pile, and spells. Secondary stats are a player preference. Teach once where relevant; expanded help lives in How to play. Errors and save limitations appear when actionable, never as perpetual development notes.

Modal entrances are about 0.2–0.26 seconds. READY breathing stays at a restrained 1.8-second cycle. Reduced motion disables decorative movement but not information. The optional resume count is three short beats, with simulation paused throughout.
