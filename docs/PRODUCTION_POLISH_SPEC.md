# v3.6.4 production review

This is an internal design/code review, not an IGN endorsement or actual staff panel.

## Art review
The old centered, framed page rectangle read like a flat UI prop and did not sit
on its shelf. The new cradle and page curvature give it a readable support, mass,
gutter and light direction. Edge highlights are muted to keep the word cards as
the highest-contrast readable objects. The first wing uses one consistent book;
later folios reuse the material without altering their existing room footprint.

## UX review
No additional panels, labels or animated noise. Original fixed reading corridor,
above-book captions, keyboard focus and Paper Pile/Wind clearance remain. Changes
to score provenance are deliberate: keeping an attractive but incomparable old PB
would mislead the player. Stars/access and historical collections remain intact.

## Release review
Quotas share the authoritative model value in the HUD, map and completion handler.
The thirteenth submission in the changed chapters does not clear; the fourteenth
clears exactly once. A fire clear still yields no chapter progress. Previous save
fixtures are genuinely produced by the supplied v3.6.3 model, not invented new-schema
objects. All runtime hashes must survive a clean full-ZIP extraction and rebuild.

## Remaining judgement
Art integration is an internal visual judgement. Automation checks containment,
determinism and execution, not player delight. Real-device input feel, long audio
sessions, human onboarding and commercial reception remain unmeasured.
