# Actual browser captures
These images come from the current standalone build running in Chromium, not generated
screen mockups. State is controlled through the test-only diagnostic seam: scores,
word density, inventories, pressure and unlocks are selected to exercise the UI.
They do not represent human performance or real online competitors. WebP files are
compressed copies of captured PNGs; artwork in the game has not been changed.
