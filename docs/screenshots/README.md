# Captured application screens

Screenshots are captured from the real shipping standalone application running in
Chromium memory with diagnostic fixtures. They are not image-generated concepts
or records of independent human gameplay. Input, model and rendering code are actual.
The new 20–24 images show pressure/typing, WIND release, score count, audio settings
and final results. Older 01–14 filenames were regenerated by the regression suites.
WebP copies are space-saving exports of those actual captures.

The opaque-origin inline environment cannot provide real localStorage; result screens
therefore truthfully show save-export advice. No screenshot establishes deployed
Vercel persistence, native Steam behavior or exact original-video fidelity.
