# Typekeeper: Enchanted Library — v3.3.5

Book-page cards and subtle spell instructions. Built directly from the full v3.3.2
release; its randomized runs, single-line word painter, balance, saves, campaign,
artwork, music, effects and keyboard rules are retained.

## Play locally

Stop the previous local server with Control+C first to reuse its address and saves.
Extract the full ZIP, then on macOS:

```bash
cd "$HOME/Downloads" &&
unzip -o "Typekeeper_Enchanted_Library_v3.3.5_Full_App.zip" &&
cd "$HOME/Downloads/Typekeeper_Enchanted_Library_v3_3_5" &&
bash START_MAC.command
```

The launcher verifies the prebuilt file hashes and prints the folder, version and
build fingerprint. It uses port 4332, or the next free port if occupied. The browser
tab must say **Typekeeper: Enchanted Library — v3.3.5**. A different local port is a
different browser-storage address; use Records → Export/Import save when moving.
Nothing here kills an existing server or writes to your GitHub/Vercel account.

No Node package installation, account or API key is needed to play. The Mac launcher
uses installed Python 3 first and installed Node.js second. Windows and Linux
launchers are included. `PLAY.html` is the embedded no-server alternative.

## What is new

Falling words now sit on a small bound folio: a narrow cloth binding, three paper-edge
layers, head/tail bands, a shaded gutter, marginal ruling and a curled outer corner.
FIRE, ICE, SLOW, WIND and bonus leaves retain distinct materials. These are cached
Canvas surfaces; words are still native text on ONE baseline, not text baked into
an image. The same surface appears during shelf arrivals and material death effects.

A single quiet caption beneath each spell pairs its existing key with its function:

| Spell | Always-visible line |
|---|---|
| FIRE | `1` Clear words |
| ICE | `2` Freeze words |
| SLOW | `3` Slow words |
| WIND | `4` Clear pile |

The tiny outlined digit is a key indicator. Press the key or click the book/caption.
Longer details remain in the existing tooltip. Captions stay steady, don't pulse,
and remain readable in high contrast. They do not introduce a new footer or HUD bar.
READY glows and tooltip anchors keep their previous size/position.

## What stays the same

**Enter submits each word.** Keys 1–4 preserve the current word and selection.
New game/Retry randomize the vocabulary; Continue resumes the saved attempt.
The v3.2.1 balance profile remains: zero campaign starter spells, two charges per
spell, scarce early rewards, and the same speed progression. FIRE clears live
cards; WIND only clears the missed-paper pile; ICE lasts six seconds and SLOW eight.
Queued SLOW, no-waste guards, deterministic Continue, local records, chapter unlocks,
mastery, practice, Endless, music and effects are unchanged. No online leaderboard
or other backend is added.

The existing v3.2.1 storage key and schema remain in use. v3.3.2 records do not become
Legacy merely because the appearance changed. Save exports identify app 3.3.5.

## Source and prebuilt builds

- `src/`: complete browser application and procedural folio artwork.
- `public/assets/`: existing local runtime art and audio, unchanged.
- `asset-source/`: retained editable art/music sources and production notes.
- `dist/`: verified modular static site, ready for a static host.
- `PLAY.html`: the complete embedded playable edition.
- `tests/`, `e2e/`, `scripts/`: logic, actual Canvas, keyboard, browser and release tests.
- `docs/qa/`: evidence from this iteration; previous evidence is under `docs/archive/`.

```bash
npm ci --offline --ignore-scripts --no-audit --no-fund
npm test
npm run check
npm run build
```

Browser QA needs the dependencies in `e2e/requirements.txt` plus a Chromium
executable. The commands below use the restricted-environment fixtures:

```bash
python3 e2e/browser_tests.py --inline --executable /usr/bin/chromium
python3 e2e/single_row_release.py --executable /usr/bin/chromium
python3 e2e/single_row_release.py --mode modules --executable /usr/bin/chromium
python3 e2e/book_leaf_tests.py --executable /usr/bin/chromium
python3 e2e/book_leaf_tests.py --mode modules --executable /usr/bin/chromium
python3 scripts/release-audit.py
```

Use your installed Chromium path on another OS. Normal players do not need these
QA tools. Browser fixture tests are not a claim of live Vercel/actual Mac testing.

## Existing linked project

`bash scripts/apply-update.sh /absolute/path/to/your/existing/Typekeeper/project`
backs up the old game before copying, preserving `.git`, `.vercel`, `.env*`,
`node_modules`, and an existing `vercel.json`. A missing target is rejected rather
than silently creating a different project. Use the separate-folder launcher above
when no old project remains. Export saves before updating or switching origins.

No font binaries are bundled. The system serif and sans-serif font stacks remain.
The folio materials are authored Canvas geometry, not extracted original-game art.
See `docs/QA_REPORT.md` for observed checks, limitations and test-harness corrections.
