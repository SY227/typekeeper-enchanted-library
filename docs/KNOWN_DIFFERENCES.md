# Scope and remaining release gates — 3.1
The supplied archive is a complete, runnable browser build with full source/assets.
It is not a Steam-installed desktop binary or a certificate of AAA quality.

Changes are based on the attached v3.0 code and the user's mechanics request. No new
frame-by-frame/video-audio analysis was performed or assumed. Original-video parity
and original-publisher affiliation are not claimed. New rules are explicitly versioned.

Automated browser checks run the embedded game in Chromium on Linux. HTTP/file navigation
is blocked by the managed browser, so server payload verification is separate. Actual
Safari, Firefox, Edge, Windows/macOS launchers, physical keyboards, high-refresh displays,
phone virtual keyboards, live hosting and Steam Overlay/Cloud/Deck are not certified.

Synthetic bots see exact live word strings, have fixed acquisition delays/keystroke
budgets and defined errors/strategies. They do not model real reading, distraction,
learning, fatigue, enjoyment or retention. Resource-assisted Endless soaks deliberately
inject inventory to stress long lifecycle paths; they are not fair human-play claims.
Human first-time/intermediate/expert sessions remain a release gate.

The keyboard is essential. Do not advertise full controller or handheld compatibility
based on viewport scaling alone. Local records are editable and not online verified
rankings. New-rule and legacy totals are separated, but that is not an anti-cheat system.

Assets/music were preserved, not newly authored. Their earlier provenance and any needed
commercial identity/asset review remain relevant. Unreal/Blender helper scripts are
unchanged, optional and unexecuted; no native-engine port was made.

See STEAM_READINESS.md for current platform context and the remaining distribution gates.
